# Формат `classifier.ekp`, версия 1

Таблица маршрутизации ядра. Собирается `tools/compile_ekp.py` из
`data/classifier/classifier.json` и `data/classifier/ui_services.json`,
читается `core/src/ekp/ekp.c` через отображение в память.

Все числа — little-endian. Каждый раздел начинается со смещения, кратного 8.

## Заголовок — 64 байта

| Смещение | Тип | Поле |
|---|---|---|
| 0 | `char[8]` | `"A112EKP\0"` |
| 8 | `u32` | версия формата = 1 |
| 12 | `u32` | число флагов (≤ 32) |
| 16 | `u32` | число служб (≤ 256) |
| 20 | `u32` | число территориальных классов (≤ 32) |
| 24 | `u32` | число происшествий |
| 28 | `u32` | число записей маршрутизации |
| 32 | `u32` | смещение таблицы имён |
| 36 | `u32` | смещение таблицы происшествий |
| 40 | `u32` | смещение таблицы записей |
| 44 | `u32` | смещение строк |
| 48 | `u32` | размер строк |
| 52 | `u32` | размер файла |
| 56 | `u32` | FNV-1a 32 от байтов `[64, размер файла)` |
| 60 | `u32` | 0 (резерв) |

## Разделы

- **Имена** — `u32`-смещения в разделе строк: сначала флаги, потом службы,
  потом территориальные классы, последним — версия классификатора-источника.
  Индекс флага — номер бита в маске флагов; индекс службы — номер бита в `a112_route.services`.
- **Происшествия** — записи по 12 байт `{code: u32, first: u32, count: u32}`,
  строго по возрастанию `code` (двоичный поиск).
- **Записи маршрутизации** — по 8 байт `{target: u16, kind: u8, cond: u8, mask: u32}`:
  - `kind` 0 — служба (`target` — индекс службы), 1 — территориальный класс;
  - `cond` 0 — всегда, 1 — выбраны все флаги `mask`, 2 — не выбран ни один флаг `mask`.
- **Строки** — UTF-8, каждая завершается `\0`; последний байт раздела — `\0`.

Информационные получатели (не видны на АРМ-112) и значения «нет реагирования»
в таблицу не попадают — их отбрасывает компилятор.

## Проверки при открытии

Сигнатура и версия, размер файла, контрольная сумма, границы и выравнивание
всех разделов, завершённость строк, возрастание кодов, диапазоны `first + count`,
`target`, `kind`, `cond`, отсутствие битов маски вне числа флагов.
Файл, не прошедший проверку, не открывается (`A112_ERR_FORMAT`).
